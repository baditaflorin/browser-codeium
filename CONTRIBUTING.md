# Contributing

Thanks for helping improve browser-codeium.

## Local Setup

```sh
npm install
make install-hooks
make test
```

## Commit Style

Use Conventional Commits:

- `feat: add editor workspace`
- `fix: handle parser load failure`
- `docs: document pages deployment`
- `test: add project storage tests`

Do not commit secrets, local `.env` files, generated logs, or private keys.
