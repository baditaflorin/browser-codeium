# 0063 - Half-Baked Feature Triage Decisions

## Status

Accepted

## Context

Several areas feel like a workspace but do not yet complete the loop for real users.

## Decision

- Workspace import: finish.
- Workspace export/import round-trip: finish.
- Small-state URL sharing: finish.
- Assistant draft copy/export affordances: finish.
- BYO-key future-facing hint: hide from production copy until real.
- Print/PDF: cut from scope and document as a limitation.
- Remote URL import: cut from scope and document as a limitation.

## Consequences

- Visible scope gets tighter and more honest.
- The product becomes more useful without pretending to be broader than it is.

## Alternatives Considered

- Leave future-facing hints in place: rejected because they create expectation debt.
